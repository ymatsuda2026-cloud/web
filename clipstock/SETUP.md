# ClipStock — 導入手順

動画ナレッジの画面を、書庫（`/books`）と同じ作りに組み直したものです。名前は **ClipStock**。

```
Mac mini                                web-archive (GitHub private)         ブラウザ(ClipStock)
 文字起こし(既存) ─→ Notion ──┐
                                ├─ clipstock_export.py ─→ *.age(暗号化) ─→ 読むだけ・復号は端末の中
 要約の依頼 ←─ GAS ←──────────┘                                              ↑ 一覧は Notion を叩かない
   (Gemini は GAS 側のキー)                                                    要約の依頼だけ GAS 経由
```

- 一覧・本文・サムネは **web-archive の暗号化ファイルだけ**を読みます。Notion は叩きません（速い理由）。
- **マーカー・メモ・読了は、暗号化して web-archive に同期**します（書庫と同じ作り。GAS も Notion の列も要りません）。
- 要約の依頼だけが GAS → Notion に行きます。Notion と Gemini のキーはブラウザに置きません。
- 一覧に並ぶのは **状態が「要約済み」のものだけ**です。

---

## 1. web-archive を作る（1回）

1. GitHub（ymatsuda2026-cloud）に **private** の `web-archive` を作る（README 付きで可）。
2. Mac に clone：
   ```sh
   git clone git@github.com:ymatsuda2026-cloud/web-archive.git ~/clipstock-archive
   ```
   cron から push するので、パスフレーズなしの SSH 鍵か、キーチェーンに入った認証が必要です。
3. ブラウザ用の **読み取り専用トークン** を作る：GitHub → Settings → Developer settings →
   Fine-grained tokens → 対象は `web-archive` だけ、Repository permissions の **Contents を Read and write**。
   （書き込みは、マーカー・メモ・タグ・種別・読了の同期にだけ使います。Read-only のトークンでも読めますが、同期できません。）

## 2. Mac：書き出しスクリプト

```sh
python3.14 -m venv ~/clipstock-venv                          # 専用の環境(書庫の venv とは分ける)
~/clipstock-venv/bin/pip install pyrage requests pillow     # pillow は無くても動く(サムネが大きいまま)
mkdir -p ~/scripts && cp <ダウンロードしたもの>/scripts/clipstock_export.py ~/scripts/
```

`~/.clipstock.env`（既存の `~/.video_notion_sync.env` を流用するなら `CLIPSTOCK_ENV=` で指す）：

```
NOTION_TOKEN=secret_xxxxxxxx
ARCHIVE_DIR=/Users/yuya/clipstock-archive
```

- `WEB_NOTION_TOKEN=` は、web記事DBを動画DBとは別の統合に繋いでいるときだけ書きます（省略すると `NOTION_TOKEN` を使います）。
- `VIDEO_DB_ID` / `WEB_DB_ID` は省略で既存と同じです。`WEB_DB_ID=` と空にすると web を読みません。
- 初回は 800 件を超える場合、本文の取得に10〜20分かかります（Notion の制限に合わせて 3 回/秒で進めます）。2回目以降は差分だけです。

初回だけ鍵を作る：

```sh
/opt/homebrew/bin/python3.14 ~/scripts/clipstock_export.py --init
```

`~/.config/clipstock/key.txt` ができます。**この鍵を失うと web-archive は誰にも読めなくなります。**
パスワードマネージャ等に控えてください（GitHub には上げない）。

動作確認 → 本番：

```sh
/opt/homebrew/bin/python3.14 ~/scripts/clipstock_export.py --dry-run   # 何も書かず、やることだけ表示
/opt/homebrew/bin/python3.14 ~/scripts/clipstock_export.py             # 差分だけ書き出して push
```

2回目以降は Notion の「最終更新」が変わった分だけ書き直します（変更なしなら 0 ファイル）。
cron の例（1時間おき。文字起こしのバッチのあとに回す）：

```cron
15 * * * * /opt/homebrew/bin/python3.14 /Users/yuya/scripts/clipstock_export.py >> /Users/yuya/clipstock_export.log 2>&1
```

web-archive の中身は次のとおり（すべて age で暗号化済み）。

```
index.json.age        一覧（全件・状態つき。本文は入れない）
notes.json.age        旧形式のマーカー（Notion の本文に入っているもの）とメモ
night.json.age        文字起こしの状況（夜間処理画面）
items/<id>.json.age   1件ぶんの本文（要約・分野別・応用・活用・マップ・文字起こし）
clipstock-state.json.age  マーカー・メモ・読了（ClipStock が書く。Mac の書き出しは触りません）
thumbs/<id>.jpg.age   サムネ（幅360）
```

## 3. GAS：要約の窓口

既存の動画ナレッジの GAS（`gas/Code.gs` のプロジェクト）に足します。

1. **`gas/Code.gs`（完全版）を、プロジェクトのメインのファイル（`Code.gs` / `code.gs`）に丸ごと貼る**（中身を全部消してから貼る）。
   旧画面の Code.gs に、下の2行を足し済みのものです。**`doPost` と `saveField_` が無いと、保存はすべて「つながらない」ように見えます。**
   あわせて `Summarize.gs` を、別のファイルとして貼ります。
2. （1 の完全版を使う場合は不要）旧画面の Code.gs を自分で直すときは、`doPost` の `switch (body.action)` に2行を足す（`default:` の手前）：
   ```js
   case 'summarize':     result = csSummarize_(body.pageId, body.source); break;
   case 'importSummary': result = csImportSummary_(body.pageId, body.json, body.source); break;
   ```
   （GAS は、要約の依頼と、Claude の返答の取り込みにだけ使います。マーカー・メモの保存には使いません。）
3. スクリプトプロパティを足す：

   | キー | 値 |
   | --- | --- |
   | `GEMINI_API_KEY` | Gemini の API キー（必須） |
   | `GEMINI_MODEL` | 省略で `gemini-2.5-flash` |
   | `APPLY_CONTEXT` | 応用の切り口。省略可。例：`受託開発・SES・保守運用の現場` |

4. デプロイ → デプロイを管理 → 編集 → **新しいバージョン**で更新（URL は変わりません）。
   既存の `NOTION_TOKEN` と `ACCESS_TOKEN` はそのまま使います。
   新しいプロジェクトに作った場合は、デプロイの設定を次のとおりにします。
   - 種類：ウェブアプリ
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（「自分のみ」のままだと、ブラウザからつながらず、保存が「窓口につながりませんでした」で失敗します）
   - 登録する URL は、`/exec` で終わるウェブアプリの URL です（`/dev` は不可）。

   つながるかどうかは、下の 7.（診断）で調べます。ClipStock の画面には、接続確認のボタンはありません。

5. **承認（新しいプロジェクトでは必須）**：初回は、スクリプトが外部サービスや設定を使うための権限を、あなたが承認する必要があります。
   承認前は、ブラウザには「つながらない」ように見えます。エディタに次の関数を足して、1回だけ実行してください。
   ```js
   function authorize() {
     UrlFetchApp.fetch('https://api.notion.com/v1/users/me', { muteHttpExceptions: true });
     PropertiesService.getScriptProperties().getKeys();
   }
   ```
   関数に `authorize` を選んで「実行」→「権限を確認」→ アカウントを選ぶ →「詳細」→「（プロジェクト名）に移動」→「許可」。
   そのあと、もう一度「デプロイを管理」→ 編集 → 新しいバージョンで更新します。
6. **スクリプトプロパティの引き継ぎ**：プロパティはプロジェクトごとの設定で、複製されません。新しいプロジェクトにも、
   旧プロジェクトと同じ `NOTION_TOKEN`・`ACCESS_TOKEN`（web記事DBを使うなら、その分も）と、`GEMINI_API_KEY` を入れてください。
7. **診断（つながらないとき）**
   - エディタで関数 `csSelfTest` を選んで「実行」→「実行ログ」。プロパティの設定漏れ、貼り付けの不足（`doPost` や `saveField_` が無い）、
     `doPost` に case を足し忘れていないかが分かります（何も保存しません）。
   - 有効なデプロイの URL をブラウザで開くと、デプロイされている版の中身が JSON で出ます
     （`doPost` / `summarize` / `importSummary` / `saveField` と、プロパティの有無。値は出ません）。
     「スクリプト関数が見つかりません: doGet」と出る場合は、デプロイされている版が古いので、**新しいバージョン**でデプロイし直します。
   - **コードを変えたら、必ず「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→ デプロイ。** 保存しただけでは、公開中の版は変わりません。
8. **URL の取り違え**：「デプロイを管理」には、有効なデプロイと「アーカイブ済み」が並びます。
   登録する URL は、**有効なデプロイの URL**（「コピー」ボタンで全体をコピー）です。アーカイブ済みの URL は使えません。

## 4. 画面を置く

`web` リポジトリの `clipstock/` で、旧画面を退避して新しい画面を置きます。

```sh
cd web/clipstock
git mv index.html old.html          # 旧画面。src/ css/ はそのまま使えるので残す
cp <ダウンロードしたもの>/{index.html,sw.js,manifest.webmanifest,icon-192.png,icon-512.png} .
cp <ダウンロードしたもの>/gas/Summarize.gs gas/
```

GitHub Pages で `https://ymatsuda2026-cloud.github.io/web/clipstock/` を開くと、鍵の画面が出ます。

初回の登録で入れるもの：

| 項目 | 値 |
| --- | --- |
| GitHub のユーザー名 / リポジトリ | `ymatsuda2026-cloud` / `web-archive` |
| アクセストークン | 1. で作った読み取り専用トークン |
| 復号の鍵 | `~/.config/clipstock/key.txt` の `AGE-SECRET-KEY-1…` の1行 |
| 要約の窓口（GAS の URL） | 3. でデプロイした `/exec` の URL（空欄なら閲覧のみ） |
| 窓口の共有トークン | GAS の `ACCESS_TOKEN` と同じ値 |
| 合言葉 | 8文字以上。忘れたら「設定を消して最初から」で入れ直し |

トークンと鍵は合言葉（PBKDF2 60万回 → AES-GCM）で包まれ、この端末のブラウザにだけ保存されます。
登録時に「リポジトリが見えるか」「その鍵で一覧が開けるか」を確かめます。

---

## Face ID・Touch ID で開く（書庫と同じ）

合言葉の代わりに、顔認証・指紋で開けるようにできます。**合言葉でも、これまでどおり開けます。**

- **登録**：開いたあと、「⚙ 表示」→「Face ID・Touch ID で開く」→「登録…」→ いまの合言葉を入れて「登録する」→ 端末の本人確認。
- **開く**：鍵をかけた画面（合言葉の入口）に、「**Face ID・Touch ID で開く**」が出ます。押して本人確認が通ると、合言葉なしで開きます。
- **解除**：「⚙ 表示」→「解除」。この端末の登録が消えます。「この端末の設定を消して、最初から設定する」でも消えます。
- **しくみ**：WebAuthn の PRF 拡張で、端末の認証器だけが出せる値を作り、それで**合言葉を暗号化して**、この端末に置きます。合言葉そのものは、どこにも残りません。端末ごとの登録です（ほかの端末は、それぞれ登録します）。
- **使える条件**：https で開いていて（GitHub Pages ならそのまま）、PRF に対応した OS・ブラウザ（iPhone・iPad・Mac の Safari、Chrome など。新しい版が目安）。対応しない場合は、「⚙ 表示」に理由が出て、登録の入口は出ません。
- 確認の範囲：登録は、実ブラウザ（Chromium の仮想認証器）で確認しました。開く（解錠）は、偽の認証器を使った自動テストで確認しています。実際の iPhone・Mac での顔認証は、まだ試していません。

## Claude.ai の要約ページ（アーティファクト）

要約待ちを**一覧から選んで、Claude で要約する**ページです。Claude.ai の中で動き、Notion の読み書きに、Claude.ai の Notion コネクタを使います。
ClipStock の「変換管理」→「Claude.ai で要約待ちを変換」から開きます（上の「使い方」）。ページの元データは `claude-artifact/clipstock-summarize.html` です。

- **前提**：Claude.ai に Notion のコネクタを追加してあること。初めて使うとき、Claude.ai が「Notion の読み書き」と「Claude の利用」の許可を聞きます。要約に使う Claude の利用量は、開いた人（あなた）の Claude アカウントにかかります。
- **画面**：上に件数と「↻ 再取得」。題名で探す・並べ替え（新しい順・古い順・短い順・長い順）・「重複を隠す」。各行にチェックと、状態（待機中・要約中・要約済み・失敗）。下の帯に、選んだ件数・字数・目安の時間と、「すべて選ぶ」「解除」「選んだものを要約する」。
- **重複**：同じ動画が複数あるときや、すでに要約済みの動画と同じものは「重複」にして、選べません（隠せます）。削除は、ClipStock の変換管理から行います。
- **1件ごとの流れ**：文字起こしを読む → Claude が5項目（サマリ・マップ・分野別・応用・活用）に要約 → Notion に5項目を書く（状態はまだ変えない）→ **読み直して、最後まで保存されたか確認** → 状態を「要約済み」にする。
  確認できなければ、状態は「完了」のまま、行に理由を出します（Notion が長い文字列を途中で切ったときの安全のため）。
- **時刻**：文字起こしに実在する `[m:ss]` だけを残します（Claude が作った存在しない時刻は取り除きます）。
- **止める**：「止める」で、要約中の1件を中断し、残りは始めません。何も書き込みません。
- **つながらないとき**：Notion が未接続・再接続が必要・許可が必要、のそれぞれで、別々の案内を出します。Claude.ai の外で開くと、見本の題名の**デモ表示**になります（何も書き込みません）。
- **注意**：要約中は、ページを開いたままにしてください。反映は、このあと Mac の書き出し（`clipstock_export.py`）が動いてからです。
- **未確認**：`notion-update-page` による実際の書き込みは、この環境では試していません（ほかの読み取りは、実際の Notion で確かめた形のままです）。**最初は、短い動画1件だけで試して**、Notion の列に最後まで入っているかを見てください。

## Claude.ai のスキル（チャットで頼むとき）

`claude-skill/clipstock-summarizer.zip`（中身は `clipstock-summarizer/SKILL.md`）を、Claude.ai に入れます。

1. 先に、Claude.ai の「設定」→「機能（Capabilities）」で、**コード実行とファイル作成**（新しい画面では「ファイルの作成と編集」）をオンにする。オフだと、スキルのメニューが出ません。
2. 「カスタマイズ（Customize）」→「スキル（Skills）」を開き、「＋」→「＋ スキルを作成」→「**スキルをアップロード**」を選んで、`clipstock-summarizer.zip` を選ぶ。
   （古い画面では「設定」→「機能」→「スキル」→「スキルをアップロード」。）
3. 一覧に出た `clipstock-summarizer` を**オン**にする。
4. Notion のコネクタを有効にしておく（動画DBに書き込める統合であること）。
5. 旧スキル `video-summarizer`（要約300〜500字・Markmap HTML）は形式が違うので、有効なままだと取り違えます。ClipStock 用には無効にするのがおすすめです。

使い方は、Claude.ai のチャットで「ClipStock の要約待ちを表示して」と頼みます（要約ページ（アーティファクト）が使えないとき、または、チャットで進めたいとき）。ClipStock の「Claude.ai で要約待ちを変換」の「チャットで開く」からも始められます。

- **1回に変換するのは、文字起こしの合計6万字（5〜6本）まで**が目安です（会話の長さの制約）。残りは「続けて」で次の回へ。
- 最初の1本は、書き込んだあとに読み直して、長い文字列が最後まで保存されているかを確認します。切れている場合は、書き込まずに
  生成した内容を会話に出して止まります（状態は「完了」のまま）。
- 書き込みが終わったら、Mac の書き出し（`clipstock_export.py`）のあと、ClipStock の「↻ 更新」で一覧に並びます。

## 使い方

書庫（`/books`）と同じ作りに合わせてあります。

- **一覧**：サムネ主体。題名は明朝・太字・2行までで、下に種別と日付、その下に「**目次・記録 ›**」。
  **サムネイルがあるものは、背景に文字を入れません**（読み込めなかったときだけ題名を出します）。サムネが無いものは、題名から決まる色の表紙に題名を載せます。前回開いたあとに要約され、まだ開いていないものには「新着」が付きます。
  小・中・大で並べる数を変えられます。
- **全画面**（一覧の「全画面」ボタン。以前の「広げる」）：一覧が画面いっぱいになります。**この状態でサムネイルを押すと、詳細（本文）も全画面に切り替わり**、
  「**‹ 一覧へ**」で全画面の一覧に戻ります（「目次・記録 ›」の目次から開いたときも同じ）。もう一度押す（「全画面を終了」）と、一覧と本文の2画面に戻ります。
  本文の上の「全画面」は、これとは別に、上の帯と一覧を隠して本文だけにするボタンです（書庫と同じ）。
- **スマホ**：読む画面では、**上のヘッダ・題名・ボタンの帯を隠し**、本文を画面いっぱいに出します。**画面を押すとスライドで出て**（約6秒で、または、もう一度押すと隠れます）、
  「‹ 一覧へ」で一覧に戻ります。リンク・マーカー・文字の選択をしているときは、出し入れしません。スマホ幅では、一覧の「全画面」ボタンは出しません。
- **目次・記録 ›**：押すと、一覧の場所に詳細が開きます（「‹ 一覧へ」で戻る）。
  - **目次**：サマリ・分野別・応用・活用・文字起こし・マインドマップ。選ぶと、本文欄にそれが出ます。
  - **記録**：開いた回数・読んだ時間・読了（「読了にする」）と、この動画に引いたマーカーとメモの一覧（押すとその場所へ）。
- **本文**：サマリ・分野別・応用・活用を1つの流れで。**横書きは縦スクロール**、縦書きは右から左へ横スクロール。
  上のボタンは 縦書き／横書き・A−/A＋・**目次**・**記録**・▶動画を開く・⚙表示・全画面。
  「目次」と「記録」は、一覧の詳細と同じ内容が小窓で開きます（「目次」の小窓から再要約もできます）。
- **マーカー・メモ**（書庫と同じ）：本文の文字を選ぶと、選んだ文の近くに「**重要・疑問・使える・メモ・コピー**」が出ます。
  色を押すとマーカー、「メモ」を押すと黄色で付いてメモを書く小窓が開きます。
  色の付いた所を押すと「**マーカー・メモ**」の小窓（引用・色の変更・メモ・消す・保存）。メモ付きの所には点線の下線が付きます。
  マーカーとメモは、この端末と web-archive に**暗号化して**保存され、別の端末にも出ます。2台で同時に変えても、新しい方が残ります。
  **同期のしくみ**：タグ・マーカー・メモ・読了の変更は、**数秒（約3秒）のうちに**送ります（読んだ位置だけは、90秒ごと・閉じるときにまとめて）。
  取り込みは、**開いたとき・画面に戻ったとき・開いたまま2分おき・「↻ 更新」を押したとき**に行い、タグのメニュー・一覧・本文のマーカーを描き直します。
  最後に同期した時刻は、上の状態の行（「記録の同期 hh:mm」）に出ます。送れないとき（トークンの書き込み権限が無いなど）は、画面に理由を出します。
  旧画面や Notion の本文に入っていた旧形式のマーカー（`<m1>…</m1>`）は、そのまま色付きで出ます（ここでは変更できません。「ノート」で「旧マーカー」として見られます）。
- **ノート**（上の「ノート」）：引いたマーカーとメモを集めて見ます。色（重要・疑問・使える）・メモあり・旧マーカーで絞れ、押すとその場所へ飛びます。
- **⚙ 表示**：**本文のフォント**を10種から選べます（しっぽり明朝・BIZ UDP明朝・Noto Serif JP・Zen Old Mincho・BIZ UDPゴシック・
  Noto Sans JP・Zen Kaku Gothic New・Klee One・端末の明朝・端末のゴシック）。選んだ書体だけ Google Fonts から読み、この端末で覚えます。
- **全画面**（書庫と同じ）：上の帯と一覧を隠して、本文だけにします。「全画面を終了」か Esc で戻ります。
- **マインドマップ**：共通API（`web/api/mindmap2/mindmap2.js`）を呼び出して表示します。`web` リポジトリの `api/mindmap2/` を、
  `clipstock/` と同じサイトに置いてください（`../api/mindmap2/` を読みに行きます）。描画ライブラリ（d3・markmap）は jsdelivr から読みます。
  枝の `[mm:ss]` を押すと、この画面のプレーヤーで再生します。読み込めないときは、理由を出して折りたたみの一覧に切り替わります。
- **動画の再生**：`[mm:ss]` の時刻、または「▶ 動画を開く」で、画面の中に再生画面が出ます（YouTube）。
  ヘッダーをつかんで**移動**、右下のつまみで**大きさ変更**（16:9 のまま）、小・中・大のボタン、✕で閉じる。位置と大きさは覚えています。
  Web 記事など YouTube 以外は、別タブで開きます。
- **Claude.ai で要約待ちを変換**（変換管理）：Claude.ai で公開した**要約ページ（アーティファクト）**を開きます。ページが、Notion の動画DBで 状態＝完了 の動画を
  **一覧で表示 → 選んだものを Claude が要約 → Notion に書き込み**まで行います（くわしくは、下の「Claude.ai の要約ページ」）。
  初回だけ、ページのリンクを貼って保存します（暗号化して記録に入り、ほかの端末でも、押すだけで開きます）。右の「⚙」で、リンクを変えられます。
  Gemini（GAS）を使わず、Claude で要約したいときの経路です。
- **種別**（**1件につき1つだけ**。タグと違って、複数は付きません）：はじめは「動画」「Web記事」で、1件ずつ・まとめて、好きな種別に付け替えられます。
  - **1件ずつ**：本文の上の「種別：◯◯」を押すと、使われている種別が並び、1つ選ぶと**前の種別は置き換わります**。新しい種別は、入力して Enter（30字まで）。
    「もとに戻す（動画）」で既定に戻せます。「目次・記録 ›」の詳細にも「種別」の欄があります。
  - **まとめて**：一覧の「選択」→ チェック →「**種別を設定**」で、1つに決めて、選んだ全件に付けます。
  - 上のメニュー（「種別：すべて」）で、種別ごとに絞り込めます（件数つき。使われていない種別は出ません）。一覧のサムネの下にも、種別が出ます。
  - 種別は、この記録（暗号化して同期。数秒で別の端末にも出ます）に保存します。**Notion の列は使わず、GAS にも送りません**
    （Notion の「分類」＝ music・golf・other などとは別のものです）。
- **タグ**：上のメニュー（種別の隣）でタグを選んで絞り込めます（「タグなし」もあります）。
  - **1件ずつ**：本文の上の「タグ」ボタン、または「目次・記録 ›」の詳細で、タグを追加（入力して Enter）・外す（× を押す）。入力は既存のタグが候補に出ます。
  - **まとめて**：一覧の「選択」を押すと選択モードになり（各サムネにチェック・下に帯）、タグを付けたい動画を選んで「**タグを付ける**」（既存のタグを選ぶか、新しく入力）・「**タグを外す**」。
    「すべて選ぶ」「解除」もあります。選択モードでは、タイルを押しても開きません。
  - タグは、この記録（暗号化して同期。数秒で別の端末にも出ます）に保存し、**Notion の「タグ」にも1件ずつ順に書き込みます**（GAS の `saveTags`）。ClipStock で付けたタグが優先され、Notion で直接変えた同じ動画のタグは、ここには反映されません。Notion に届かなかったものは、画面に理由を出し、次に開いたときに自動でやり直します。
    Notion のタグ名に、半角のカンマは使えないので、空白に直します。一覧のタイルには、タグは出しません。
- **重複**：同じ動画（YouTube は動画ID、それ以外は URL）が複数あるとき、要約が進んでいる方・古い方を1件だけ残し、**あとは「重複」として変換管理にだけ出し、一覧には出しません**。
  重複にできるのは「**削除**」だけです（行の「削除」、またはチェックして「重複を削除」）。確認のあと、Notion の**ゴミ箱**に移します（30日間は Notion から戻せます。GAS の `deleteVideo`）。
  残す方は削除しません。URL が違う別の動画は、題名が同じでも重複にしません。
- **変換管理**：要約待ち（文字起こし完了）を選んで「選択を要約する」（Gemini）。1本あたり1〜3分。
  要約した直後は、次の書き出しまでこの端末の中で反映されます（暗号化して保持）。

## ホーム画面に追加（ショートカットアイコン）

アイコンは、ClipStock の見た目に合わせて、**紺の布表紙に、金箔のしおり（再生マーク入り）と、積み重なった線（ストック）**にしました。

| ファイル | 用途 |
| --- | --- |
| `apple-touch-icon.png`（180×180・透明なし） | iPhone・iPad の「ホーム画面に追加」 |
| `icon-192.png` / `icon-512.png`（角丸・透明） | 通常のアイコン（Android・PC の「インストール」など） |
| `icon-maskable-512.png`（全面・透明なし） | Android の丸・角丸などに切り抜かれるとき |
| `favicon.ico` / `favicon.svg` / `icon.svg` | ブラウザのタブ・ブックマーク |
| `design/icon-full.svg` | 元データ（全面版）。変えたいときの出発点 |

追加のしかた：

- **iPhone・iPad（Safari）**：共有ボタン →「ホーム画面に追加」→ 名前を確認（ClipStock）→「追加」。
- **Android（Chrome）**：右上の︙ →「ホーム画面に追加」または「アプリをインストール」。
- **PC（Chrome・Edge）**：アドレスバー右の「インストール」マーク。**Mac の Safari**：共有 →「Dock に追加」。

古いアイコンのままのとき：ホーム画面のアイコンは、**追加した時点のものが固定**されます。以前に追加したものは、いったん削除して、追加し直してください。
ブラウザのタブのアイコンは、再読み込みで変わります（変わらないときは、ページを開き直してください）。

## 仕様上の割り切り

- マーカーは、1つの段落（または箇条書き1件）の中で引けます。複数の項目にまたがって選んだときは、最初の項目の分だけが対象です。
- 同期にはトークンの **Contents の書き込み権限**が必要です。無い場合は、画面に理由を出し、この端末にだけ残します。
- マーカーの位置は、引用の文と一緒に持ちます。再要約などで文面が変わったときは、同じ文を探し直し、見つからなければ（記録には残して）本文には出しません。
- 夜間処理は、Notion の状態の変化（新規→完了→要約済み）から作っています。文字起こしの失敗そのものは Notion に残らないので、「24時間以上、未処理のまま」を要確認として出します。
- 要約（Gemini）は GAS の実行時間（6分）に収めるため、5分を過ぎると残りの段を諦めます（画面に「◯◯は作れませんでした」と出ます）。
- 時刻リンクは AI に答えさせず、引用を文字起こしから探して付けます。見つからなければリンクは付きません。
- GAS は、リダイレクト先を気まぐれに 404 で返すことがあります。**1本ずつ2.5秒以上あけて送る・URL に毎回違う値を付ける・通信が失敗したときだけ最大5回やり直す**ようにしています。
- Face ID での開錠は付けていません。
