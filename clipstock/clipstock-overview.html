ClipStock 全体像とシーケンス

YouTube の動画や Web 記事を、Mac mini で文字起こしして Notion に集め、要約して、暗号化したまま GitHub に置き、PC とスマホのブラウザで読むアプリです。ここでは、全体の構成と、端末・サービスごとのやり取りを図にしています。

  • データを作る側（Mac・Notion・要約）
  • 見る側（保存先・アプリ）
  • 利用者・外部
  • 実線は依頼
  • 点線は返事
  • 灰色の枠は、その場で起きることやモジュール名

全体像

データの流れ

動画や記事が、Mac mini で文字起こしされ、Notion に集まり、要約され、暗号化されて GitHub に保存され、ClipStock で読まれるまで。

画面の構成

主な画面は「一覧」と「本文」の2つ。ほかに、ノート・記録・夜間処理・変換管理があります。

シーケンス

夜間・定期の裏側

Mac mini の2つのスクリプト。文字起こし（video_transcribe_notion.py）と、定期の書き出し（clipstock_export.py）。

要約（Gemini 経由）

ClipStock から窓口（GAS）に依頼し、GAS が Notion の文字起こしを Gemini で5段に要約して書き戻します。Notion と Gemini の鍵は GAS の中にあります。

要約（Claude.ai のページ経由）

ClipStock の「Claude.ai で要約待ちを変換」から、Claude.ai の要約ページ（アーティファクト）を開きます。ページが Notion の要約待ちを一覧にし、選んだものを Claude で要約して、書き込み・確認・状態の更新まで行います。

開く・読む

PC・スマホ共通。合言葉で鍵を開き、端末に保存した暗号文を先に表示し、最新を GitHub から取り直します。復号は端末の中だけで行います。

Face ID・Touch ID で開く

合言葉を、端末の認証器の値で包んで保存し、次からは本人確認だけで開きます。合言葉でも開けます。

別の端末へ（種別・タグ・マーカー・メモ）

端末Aの種別・タグ・マーカー・メモの変更は約3秒で暗号化して送られ、Notion のタグにも反映されます。端末Bは、開いたとき・戻ったとき・2分おき・「↻ 更新」で取り込みます。

重複の削除

重複は一覧に出さず、変換管理から削除だけできます。窓口が Notion のページをゴミ箱に移し（30日は戻せます）、削除の印は別の端末にも同期されます。
