    ↑↓で移動 / ←→で開閉 / スペースで編集(Enterで決定・Escで取消) / Tabで子を追加 / Enterで同じ階層に追加 / Deleteで削除

    設定

    保存先(JSONBin)

    APIキーはこのブラウザの localStorage に保存されます。共用の端末では使わないでください。

    暗号化

    AES-GCM(256bit) / PBKDF2-SHA256 で本文を暗号化します。更新日時と版数だけは暗号化されません。

    パスフレーズを忘れると誰にも復号できません。控えを別の場所に残してください。

    バックアップ

    書き出しは復号された状態の全マップです。取り込みは今の一覧に追加されます。

    パスフレーズ

    保存されている内容は暗号化されています。
