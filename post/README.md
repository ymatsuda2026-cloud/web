# X自動ポスト

Notionの元ネタから、claude.aiでXの2連スレッドを3パターン生成し、GitHub Pagesの管理画面で選んで投稿データを作るアプリです。

```
x-auto-post/
├─ gas/Code.gs      … 中継API（Google Apps Script）
└─ docs/index.html  … 管理画面（GitHub Pagesで公開）
```

## Notion

| DB | ID | 用途 |
|---|---|---|
| 抽出ポスト① | `f79a39cee9d942d1b0aadf3e6ed140fc` | 元ネタ（アカウント指定つき） |
| 生成ポスト① | `af2d2094a1b34760949e50514c1ce611` | 生成結果と状態 |
| 自動ポスト設定 | `4ae6ae06264f4d719bf852bb24d61274` | 生成指示テンプレートなどの設定 |

## セットアップ

### 1. Notionインテグレーション
1. https://www.notion.so/profile/integrations で内部インテグレーションを作成し、シークレットを控える
2. 上の3つのDBそれぞれで「…」→「接続」から、そのインテグレーションを追加する

### 2. GAS
1. https://script.google.com で新しいプロジェクトを作り、`gas/Code.gs` の内容を貼り付ける
2. 「プロジェクトの設定」→「スクリプト プロパティ」に次を追加する

| プロパティ | 値 |
|---|---|
| `NOTION_TOKEN` | 1で控えたシークレット |
| `APP_KEY` | 自分で決めた長いランダム文字列 |
| `SRC_DB` | `f79a39cee9d942d1b0aadf3e6ed140fc` |
| `GEN_DB` | `af2d2094a1b34760949e50514c1ce611` |
| `SETTINGS_DB` | `4ae6ae06264f4d719bf852bb24d61274` |

3. エディタで `checkSetup` を実行し、ログに抽出ポスト①のタイトルが出ることを確認する
4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」、実行ユーザー「自分」、アクセス「全員」でデプロイし、URL（`…/exec`）を控える
   - コードを直したときは「デプロイを管理」から同じデプロイの新バージョンを作ると、URLが変わりません
5. エディタで `installTrigger` を一度実行し、15分ごとの自動取り込みを設定する（初回は権限の承認が出ます）

### 3. GitHub Pages
1. リポジトリに `docs/index.html` を置く
2. 「Settings」→「Pages」で、ブランチを指定しフォルダを `/docs` にする
3. 公開されたページの「設定」で、GASのURLと `APP_KEY` を入力して「保存して接続テスト」を押す
4. 「生成設定を保存」を一度押すと、既定のテンプレートがNotionの「自動ポスト設定」に保存される

## 画面でできること

- **ボード**：空／生成済／候補／採用の4列で一覧表示。候補にする、再生成依頼、生成済へ戻す、削除
- **ネタを追加**：ポスト①を検索・タグで絞り込み、アカウントを選んで「生成待ち」として追加
- **編集**：3パターンを見比べ、1ポスト目・2ポスト目を編集（全角換算の文字数チェック付き）。候補として保存、採用して送信データ作成
- **手動投稿**：採用後に1ポスト目・2ポスト目のコピーと、Xの投稿画面を開くボタン
- **設定**：生成指示テンプレート、再生成時に常に付ける指示、文字数の目安と上限、パターン名、アカウントと既定の投稿方法

## 抽出ポスト①のアカウント指定から自動で生成する

抽出ポスト①の「アカウント」（複数選択）に、そのネタで投稿を作りたいアカウントを入れておきます。

1. GASが15分ごとに抽出ポスト①を見て、「アカウント」にあって「取り込み済み」にないアカウントの分だけ、生成ポスト①に状態「生成待ち」の行を作る
2. 作ったアカウントは抽出ポスト①の「取り込み済み」に自動で記録される
3. claude.aiの生成画面で「Notionから取得」すると、その「生成待ち」が並ぶので生成する。生成はその行のアカウントのペルソナ・指示で行われる

- すぐに取り込みたいときは、管理画面のボードの「抽出ポスト①から取り込む」を押す
- 生成ポスト①の行を削除しても、自動で作り直されません。同じアカウントでもう一度作りたいときは、抽出ポスト①の「取り込み済み」からそのアカウントを外す
- 管理画面の設定に登録されていないアカウント名は取り込みません（設定でアカウントを保存すると、Notionの「アカウント」の選択肢にも自動で追加されます）
- 「ネタを追加」から手動で追加した場合も、「取り込み済み」に記録されます

## 複数アカウント

Notionの3つのDBはアカウント間で共有し、生成ポスト①の「アカウント」列で区別します。管理画面の「設定」→「アカウント」で、アカウントごとに次を登録します。

| 項目 | 使われ方 |
|---|---|
| アカウント名 | ボードの絞り込み、追加先、送信データの `account` |
| 既定の投稿方法 | 編集画面でアカウントを選んだときの初期値（自動／手動） |
| 扱うネタのタグ | 「ネタを追加」の絞り込みで「このアカウントのタグのネタ」を選んだときに使う |
| ペルソナ・追加指示 | 生成時、指示の最後に足される |
| 指示テンプレート | 空欄なら共通テンプレート。入れるとこのアカウントだけ差し替え |
| 再生成のときに常に付ける指示 | 空欄なら共通の指示 |

- アカウントを1つ以上登録すると、ネタの追加と採用でアカウントの選択が必須になります
- 同じネタを同じアカウントに2回追加しようとすると確認が出ます
- ボードのアカウント絞り込みは端末に記憶されます
- claude.ai側の生成画面も、投稿のアカウントに合わせてペルソナと指示を切り替えます。キューはアカウントで絞り込めます

## 状態の移動

| 操作 | 移動 | 実行する側 |
|---|---|---|
| 自動取り込み／ネタを追加 | → 生成待ち | GAS（15分ごと）／管理画面 |
| 生成 | 生成待ち・再生成 → 生成済 | claude.ai |
| 候補にする／生成済へ戻す | 生成済 ⇄ 候補 | 管理画面 |
| 再生成依頼 | 生成済・候補 → 再生成 | 管理画面 |
| 依頼を取り消す | 再生成 → 生成済 | 管理画面 |
| 採用 | 生成済・候補 → 採用 | 管理画面 |
| 候補へ戻す | 採用 → 候補 | 管理画面 |
| 削除 | どこからでも（Notionのゴミ箱へ） | 管理画面 |

移動のルールはGASの `TRANSITIONS` で管理しています。

## 注意

- 認証キーはブラウザの localStorage に保存されます。共用端末では使わないでください
- GitHub Pagesは公開ページなので、データはGASの認証キーで守っています。キーが漏れたら `APP_KEY` を変えてください
- Xへの自動投稿（API）は未実装です。いまは送信データの作成と手動投稿の補助までです

## claude.ai側の生成画面（claude/generator.html）

claude.aiで公開しているページです：https://claude.ai/artifact/4JJoVVoHN4HtuFF314p25f

- NotionはclaudeのNotionコネクタで直接読み書きします（AIを通さないので、文面はそのまま書き込まれます）
- 生成はclaude.aiのAIで行います
- 初回はNotionの利用とAI生成の許可を求められます
- 管理画面のボードで「生成待ち」の列名、またはカードの「claude.aiで生成」を押すと開きます。カードから開くとその投稿が選ばれた状態になります
- 生成画面のURLを変えたいときは、管理画面の設定「claude.aiの生成画面のURL」に入れる

使い方：
1. 投稿を選んで「3パターン生成」（再生成の行は「依頼どおりに再生成」。対象のポストだけ作り直し、ほかはそのまま）
2. 必要ならカードごとに対象と指示を入れて「このパターンを再生成」。文面は直接直せる
3. 「Notionに登録（生成済へ）」で P1-1〜P3-2 を書き込み、状態を「生成済」にする

「表示中をまとめて生成・登録」で、一覧の投稿を順に生成して登録まで進めます。
